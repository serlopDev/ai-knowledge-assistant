# api (NestJS)

Public REST API of AI Knowledge Assistant. See the [root README](../README.md) for the overall architecture.

Generated with `@nestjs/cli` 12.0.10 (`--strict`). Endpoints are not implemented yet.

```bash
pnpm  install
pnpm run start:dev     # http://localhost:3000
pnpm test              # unit tests (Vitest)
pnpm run test:e2e      # end-to-end tests (Vitest + supertest)
pnpm run lint          # oxlint
pnpm run build
```
